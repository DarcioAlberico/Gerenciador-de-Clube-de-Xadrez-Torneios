Política de Privacidade — Albericus

Última atualização: 3 de junho de 2026

O Albericus é um aplicativo de computador (desktop), offline-first, para gestão de torneios e clubes de xadrez, usado por árbitros e organizadores. Esta política explica como o aplicativo trata os dados, especialmente no recurso opcional de criação de formulários de inscrição no Google Forms.

1. Quem somos

Responsável: Darcio Alberico. Contato: darcioalberico54@gmail.com. Página do projeto: github.com/DarcioAlberico/Gerenciador-de-Clube-de-Xadrez-Torneios.

2. Integração com o Google (Google Forms)

Quando o usuário opta por criar o formulário de inscrição diretamente pelo aplicativo, o Albericus solicita a permissão https://www.googleapis.com/auth/forms.body via "Entrar com o Google". Essa permissão é usada exclusivamente para:

  • criar e estruturar um formulário de inscrição padronizado na própria conta Google do usuário;
  • ler o link de resposta do formulário recém-criado para que o usuário possa compartilhá-lo com os jogadores.

O aplicativo não lê outros formulários do usuário e não acessa Google Drive, Gmail, Contatos, Agenda nem qualquer outro dado da conta.

3. Dados coletados pelo desenvolvedor

Nenhum. O Albericus é um aplicativo local e não possui servidores. Não coletamos, não armazenamos e não transmitimos os seus dados, o conteúdo dos formulários ou as respostas dos jogadores para nós nem para terceiros.

4. Onde ficam os dados

  • O formulário criado e as respostas dos jogadores ficam na conta Google do próprio usuário (Google Forms/Sheets dele).
  • O token de acesso do Google fica salvo somente no computador do usuário (arquivo local), para evitar novo login a cada uso.
  • Os dados do torneio ficam em um banco de dados local (SQLite) no computador do usuário.

5. Compartilhamento

Não compartilhamos dados com terceiros. O uso dos dados do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Como revogar o acesso

O usuário pode revogar o acesso a qualquer momento apagando o arquivo de token local (google_forms_token.json) ou removendo o aplicativo em myaccount.google.com/permissions.
