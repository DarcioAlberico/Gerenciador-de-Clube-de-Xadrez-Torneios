Logos padrao para diplomas do Albericus.

Arquivos:
- `albericus_knight.png`: marca circular com cavalo.
- `clube_rook.png`: escudo de clube com torre.
- `escola_pawn.png`: logo escolar com peao e livro.
- `torneio_trophy.png`: selo de torneio com trofeu.
- `selo_queen.png`: selo neutro com dama.

Todos os arquivos sao PNG com fundo transparente e podem ser usados como logo
principal ou logo secundario nos modelos de diploma.

Para recriar os arquivos, execute:

```powershell
uv run python scripts\generate_certificate_logos.py
```
