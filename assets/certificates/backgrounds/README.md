Fundos padrao para modelos de diplomas do Albericus.

Arquivos:
- `tabuleiro_sutil.png`: padrao claro para premiacao por categoria.
- `xadrez_classico.png`: visual classico para certificados de participacao.
- `xadrez_escolar.png`: visual leve para escola/turma.
- `xadrez_premium.png`: visual mais formal para premiacao geral.
- `pecas_marca_dagua.png`: pecas discretas em marca d'agua para ranking interno.

Para recriar os arquivos, execute:

```powershell
uv run python scripts\generate_certificate_backgrounds.py
```
